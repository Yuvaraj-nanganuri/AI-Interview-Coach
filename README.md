# 🤖 AI Interview Coach

AI-powered Interview Coach built using Streamlit, FAISS, Sentence Transformers, RAG and Google Gemini AI.

## Features

- Resume Upload
- PDF Parsing
- Semantic Search
- FAISS Vector Database
- RAG
- AI Interview Question Generation
- AI Interview Evaluation
- Streamlit UI

## Technologies

- Python
- Streamlit
- Google Gemini API
- Sentence Transformers
- FAISS
- PyMuPDF
- LangChain

## Installation

```bash
git clone https://github.com/Yuvaraj-nanganuri/AI-Interview-Coach.git

cd AI-Interview-Coach

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
